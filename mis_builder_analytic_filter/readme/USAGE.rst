#. Open a MIS report whose source is *MIS Account Analytic Line* (Accounting >
   Reporting > MIS Reporting).
#. Use the filter box at the top of the report to search by analytic account,
   analytic plan, analytic tag, account or company.

The report instances that already exist get the new search view when the module
is installed. Check *Show filters box* in the instance settings if the box is not
visible.
