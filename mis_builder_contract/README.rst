This module adds a new model for Actuals(alternative) MIS data sources
based on the calculation of virtual lines generated according to the
contract line dates, amounts, and recurrence intervals, for both
customers and vendors.

**Table of contents**

.. contents::
   :local:

Usage
=====

Go to Invoicing / Accounting > Reports > MIS Reports. In Columns, add a
new line, set the Data Source to Actual Data (alternative), select the
Move lines source as MIS Contract Lines, and set a date range.
